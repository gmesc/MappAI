# Transizione Medioevo

Quando le legioni romane se ne andarono, la popolazione locale non cadde nel caos ma si adattò.

## Fonti
- [Estratto]: Quando però, intorno al 401 d.C., le legioni romane ricevettero l'ordine di ritirarsi verso l'Italia per difendere Roma dalle prime grandi migrazioni, il territorio non sprofondò nel caos.
