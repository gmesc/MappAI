# Le Vicinanze

Riunioni dove si decidevano le cose importanti per il villaggio, come le riparazioni dei sentieri.

## Fonti
- [Estratto]: Le assemblee di villaggio, chiamate spesso 'vicinanze', riunivano i capifamiglia per decidere quando portare le mucche all'alpeggio o come riparare un sentiero.
