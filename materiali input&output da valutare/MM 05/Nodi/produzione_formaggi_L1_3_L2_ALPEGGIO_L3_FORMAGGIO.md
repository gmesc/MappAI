# Produzione formaggi

Il formaggio a pasta dura era usato per scambiarlo con cereali o sale.

## Fonti
- [Estratto]: La produzione di latticini a lunga conservazione (come il formaggio a pasta dura) divenne una merce di scambio fondamentale per ottenere cereali o sale.
