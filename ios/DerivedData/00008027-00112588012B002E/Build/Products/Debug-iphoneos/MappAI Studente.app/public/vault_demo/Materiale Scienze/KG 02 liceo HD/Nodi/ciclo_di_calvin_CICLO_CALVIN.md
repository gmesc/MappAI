# Ciclo di Calvin

Avviene senza bisogno di luce. La pianta usa l'energia prodotta prima per trasformare l'anidride carbonica dell'aria in zuccheri, che servono per crescere e accumulare riserve.

## Fonti
- [Estratto]: Attraverso una serie di reazioni che consumano l' ATP e il NADPH generati nella fase luminosa, si formano molecole di gliceraldeide-3-fosfato ( G3P )
