KEY DESIGN DECISIONS
────────────────────────────────────────────────────────────────────────────────

1. Vanilla JavaScript (no framework)
   → Rationale: Flexibility, no dependency churn, Electron compatibility
   → Tradeoff: More boilerplate, larger codebase (16k LOC app.js)

2. Monolithic app.js + Feature modules
   → Rationale: Core logic centralized, features modular
   → Tradeoff: Code organization needs refactoring post-launch

3. Dual AI provider (Google + Infomaniak)
   → Rationale: GDPR compliance (Infomaniak = Swiss data), Google = advanced (Gemini)
   → Tradeoff: Maintenance burden, bridge compatibility layer needed

4. D3.js for graph rendering
   → Rationale: Battle-tested, force simulation, SVG control
   → Tradeoff: Learning curve, optimization needed for large graphs

5. localStorage + Electron file storage
   → Rationale: Offline-first, retrocompatibility (iOS via Capacitor)
   → Tradeoff: Sync complexity, DAL Protocol needed
