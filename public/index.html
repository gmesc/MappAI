Usa Mapp.AI con ChatGPT/Claude

1. Copia il Prompt

Ti fornirò un testo. Analizzalo e crea una mappa mentale strutturata in formato JSON per Mapp.AI.
Usa esattamente questo schema:
{
  "nodes": [
    {"id": "ROOT", "label": "Titolo Centrale", "level": 0, "content": "Descrizione..."},
    {"id": "N1", "label": "Ramo Principale", "level": 1, "content": "..."},
    {"id": "N1_1", "label": "Sottotema", "level": 2, "content": "..."}
  ],
  "links": [
    {"source": "ROOT", "target": "N1", "rel": "include"},
    {"source": "N1", "target": "N1_1", "rel": "include"}
  ]
}
Restituisci solo il JSON pulito.

2. Salva e Importa

Copia la risposta dell'AI, incollala in un file di testo e salvalo con estensione .json. Poi usa il tasto "Importa JSON" o trascina il file direttamente qui dentro per visualizzare la tua mappa!

💡 Tip: Puoi chiedere a ChatGPT di aggiungere "content" dettagliati per ogni nodo per avere una mappa ricca di informazioni.

Come ottenere la API Key

Mapp.AI utilizza i potentissimi cervelli artificiali di Google per studiare i tuoi documenti.

  1. Vai al sito web Google AI Studio.
  2. Fai l'accesso con il tuo account Google gratuito.
  3. Clicca sul bottone blu Create API key.
  4. Copia la lunga stringa di testo (inizia con AIza...) e incollala qui nell'App Mapp.AI!
💡 Nota: Le API di tipo "Gemini 1.5 Flash" sono completamente gratuite fino a 15 richieste al minuto!
