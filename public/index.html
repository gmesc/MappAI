Come ottenere la API Key

MappAI utilizza i potentissimi cervelli artificiali di Google per studiare i tuoi documenti.

  1. Vai al sito web Google AI Studio.
  2. Fai l'accesso con il tuo account Google gratuito.
  3. Clicca sul bottone blu Create API key.
  4. Copia la lunga stringa di testo (inizia con AIza...) e incollala qui nell'App MappAI!
💡 Nota: Le API di tipo "Gemini 1.5 Flash" sono completamente gratuite fino a 15 richieste al minuto!
