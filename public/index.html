Metodo di Studio Attivo

Mapp.AI non è solo un generatore di schemi: è un ambiente di apprendimento attivo. La mappa generata dall'AI è il tuo punto di partenza — il vero studio inizia quando la personalizzi.

🔁 Ripasso Dilazionato (Spaced Repetition)

Non ripetere tutto in un giorno. Ripassa le flashcard a intervalli crescenti (1g → 3g → 7g → 14g). Mapp.AI integra un sistema di ripetizione spaziata: usa il tasto destro sui nodi per generare e ripassare le flashcard!

🧠 Active Recall (Richiamo Attivo)

Non rileggere passivamente: chiudi gli appunti e prova a riscrivere cosa ricordi. Fai doppio click su un nodo della mappa, svuota il contenuto e riscrivi con parole tue. L'atto di recuperare dalla memoria è 2–3x più efficace della rilettura.

👨‍🏫 Metodo Feynman

Spiega ogni concetto come se lo stessi insegnando a un bambino di 10 anni. Se non riesci a farlo senza intoppi, hai trovato il tuo punto debole. Usa i nodi della mappa per riscrivere le spiegazioni finché non diventano chiare e lineari.

🔀 Interleaving (Studio Alternato)

Alterna argomenti diversi nella stessa sessione di studio, invece di dedicarti a uno solo. Il cervello impara a distinguere e collegare i concetti. Usa il Knowledge Graph per visualizzare i legami trasversali tra temi!

❓ Interrogazione Elaborativa

Per ogni nodo della mappa chiediti: "Perché funziona così?" e "Come si collega al resto?". Questo livello di auto-interrogazione trasforma la lettura passiva in comprensione profonda.

📂 Collegamento File Locali

Hai degli approfondimenti sul computer? Trascina file o clicca sul nodo per collegare documenti locali (PDF, immagini, file di testo). I nodi con file collegati mostrano l'icona del database per un accesso istantaneo alle tue risorse offline.

I nodi modificati ricevono icone speciali: (testo), (immagini), (link) e (file locali). Più personalizzi, più il tuo studio diventa efficace!

Come usare Mapp.AI

📌 Passo 1 — Configura la tua API Key

Clicca il bottone "Configura AI" in alto a destra. Inserisci la tua API Key di Google AI Studio (è gratuita!). Scegli il modello AI: i modelli Flash sono gratuiti e veloci, i Pro sono più precisi ma a pagamento.

📂 Passo 2 — Carica le tue Fonti

Puoi caricare materiale da diverse fonti:
📄 PDF — Carica un file PDF dal tuo computer.
🌐 URL Web — Incolla l'indirizzo di una pagina web.
🎬 YouTube — Incolla il link di un video YouTube.
📝 Testo Libero — Scrivi o incolla del testo direttamente.

🎯 Passo 3 — Scegli il tipo di Mappa

Mappa Mentale: Struttura gerarchica (L0→L5) perfetta per lo studio. Ogni nodo ha un ruolo preciso.
Knowledge Graph: Rete di relazioni tra concetti, ideale per visualizzare connessioni trasversali.

✍️ Passo 4 — Personalizza e Guida l'AI

Scrivi il nome del Nodo Centrale (l'argomento principale). Puoi suggerire i rami L1, attivare la generazione automatica, definire il focus specifico e regolare la densità delle diramazioni profonde.

🗺️ Passo 5 — Interagisci con la Mappa

Una volta generata la mappa puoi:
🖱️ Doppio click su un nodo — Apri il pannello per leggere, modificare note e aggiungere immagini.
🔍 Scroll — Zoom in/out sulla mappa.
✋ Drag — Trascina i nodi per riorganizzarli.
📌 Click destro — Menu contestuale con opzioni avanzate (quiz, espansione, flashcard).
🔒 Fissa i nodi — Usa il bottone "Pin" nella toolbar per bloccare le posizioni.

💾 Passo 6 — Salva e Riprendi

Le mappe vengono salvate automaticamente nella cartella "Salvataggi Mapp.AI" dentro Documenti. Puoi importare/esportare i file JSON per condividerli. I progetti recenti appaiono nella barra in fondo alla landing page.

📓 Raccoglitore Appunti

Nella sidebar laterale trovi il Raccoglitore Appunti: visualizza tutte le note e immagini che hai aggiunto ai nodi. È il tuo quaderno digitale collegato direttamente alla mappa!

Mapp.AI salva tutto localmente sul tuo Mac. I tuoi dati non lasciano mai il tuo dispositivo.
