📝 How schools teach

Linear reading. Text underlining. Copying notes. Sequential memorization. These methods have not changed structurally in 150 years.

🧠 How ND brains work

Visual. Non-linear. Pattern-driven. Associative. Parallel processing. ND brains are not broken linear processors — they are powerful non-linear ones forced into the wrong format.

Semantic maps. Visual knowledge structures. Concept graphs. 40 years of science says this. Yet producing one map still takes a teacher 2–3 hours by hand.

Output modalities
Sintesi di Ramo
Branch Summary
AI synthesizes any map branch into a structured, cited text document — printable and exportable as PDF.
Dossier Nodo
Node Dossier
Full hierarchical text outline of the node's knowledge tree — structured for study, printable in one click.
Flashcard
Flashcards
Auto-generated from every map concept. Select any node or branch, shuffle, and review — all without leaving the map.
Sessione di Studio
Study Session
Configurable quiz: multiple choice, true/false, or free answer. Fluency Timer + Pomodoro. Score, error analysis, saved to Vault.
Active construction modes

Seven independent modes that turn passive review into active knowledge reconstruction — grounded in retrieval practice and spaced repetition research.

Mode 01
Build Your Map
All nodes grey — BFS from root colors each connection as you reconstruct the graph from memory.
Mode 02
Rebuild Hierarchies
Color areas pre-assigned — reconnect branches, then verify against the original tree.
Mode 03
Label Recall
All labels hidden — click each node to reveal, then self-assess ✓/✗ in real time.
Mode 04
Fill Descriptions
Write your own explanation, then compare with source text and self-evaluate the gap.
Mode 05
Find the Intruder
1–2 leaves displaced from their branch — identify and relocate them to the correct position.
Mode 06
Relation Verbs
Edge verbs hidden — click each arc and choose from semantic relation families; compare with original.
Mode 07
Sort Sequence
Branch hierarchy shuffled — reconnect nodes in the correct order and verify against the source.
Local-first storage
The Vault
Every session is saved locally — node markdown files, map JSON, quiz results, attachments, and Socratic chat transcripts. No cloud required. No lock-in.
