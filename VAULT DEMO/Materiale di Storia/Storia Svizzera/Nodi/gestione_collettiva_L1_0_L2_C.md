# Gestione Collettiva

Nelle valli alpine, l'ambiente difficile impediva il controllo di un unico signore. Le comunità crearono i 'Beni Comuni' e le 'vicinanze' per gestire insieme pascoli e foreste, gettando le basi della futura democrazia diretta svizzera.

## Fonti
- [Estratto | Originale]: La sopravvivenza dipendeva dalla gestione collettiva. I pascoli d'alta quota, le foreste per il legname e i complessi sistemi di irrigazione richiedevano un lavoro di squadra costante.
